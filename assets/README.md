# assets

Your own art for the Archive. Nothing in this folder is committed except this note: the repo is
public and character art is not ours to publish.

Drop the host's picture here and name it in `config.yml` (`host.art`, default `/assets/host.webp`).
A transparent WebP or PNG, around 600 px tall, looks best. Until the file exists, a silhouette
stands in. compose.yml mounts this folder read-only at `/app/assets`.
